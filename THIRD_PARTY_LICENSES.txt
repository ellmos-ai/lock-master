## Core Runtime

The base package declares zero external runtime dependencies (`dependencies = []`).
The entire runtime execution relies strictly on the official Python Standard Library.

| Package / Module | Scope | Version Spec | License | Purpose |
|---|---|---|---|---|
| Python Standard Library | Runtime | >=3.10 | PSF-2.0 | Core runtime: argparse, contextlib, dataclasses, datetime, fnmatch, hashlib, importlib, inspect, io, json, logging, os, pathlib, platform, re, shutil, signal, socket, sqlite3, stat, sys, tempfile, threading, time, typing, uuid |
| tomli | Runtime Fallback (<3.11) | >=2.0.0 | MIT | Python 3.10 TOML parsing compatibility fallback |

All core mutex stamping, active lock scanning, TTL evaluation, fencing tokens, permission rule matching, and team coordination are handled 100% through Python standard library primitives.
Zero third-party telemetry, analytics, cloud synchronization, or remote networking services are packaged or contacted.

## Zero-Copyleft Guarantee & Unprivileged Execution

- Zero-Copyleft Guarantee: All runtime code and development dependencies are governed strictly by permissive, business-friendly open-source licenses (MIT, Apache-2.0, PSF-2.0, BSD-3-Clause). The codebase contains zero GPL, AGPL, or viral copyleft components.
- Unprivileged User-Mode Operation (RunAsInvoker): All CLI commands, lock files, atomic renames, SQLite watcher storage, and state queries execute purely within unprivileged user space. No administrative rights, root elevation, sudo, or UAC prompts are ever required.

## Governance & Runtime Invariants

`lock-master` strictly enforces ten foundational governance and runtime invariants:
- INV-LOCAL-01: 100% Local-First & Zero-Egress (100% offline-ready; local filesystem locks; zero network calls or telemetry)
- INV-SEC-02: Unprivileged User-Mode Execution (RunAsInvoker; executes in unprivileged user space without elevation)
- INV-FAIL-03: Fail-Closed Default Semantics (ambiguity, syntax errors, or unexpired locks default to access denied / read-only)
- INV-SCOPE-04: Hierarchical & Scoped Locking (root LOCK.txt protects repo; granular LOCK.<scope>.txt enables safe concurrency)
- INV-TEAM-05: Multi-Agent Team Coordination (LOCK.team.<host>.txt coordinates intra-host agent teams and FIFO queues)
- INV-TTL-06: Deterministic TTL & Safe Stale Pruning (explicit expires_after duration; prune_stale_locks.py safe --dry-run)
- INV-PERM-07: Declarative Permission Engine (evaluates LOCK.permissions.json using deny > ask > allow > default hierarchy)
- INV-AUDIT-08: Read-Only Inspection & Atomic Cache (lock_scan.py runs read-only; LOCK-CACHE.md written atomically)
- INV-LIC-09: 100% Permissive Audited Stack (zero external runtime dependencies; 100% permissive dev dependencies; NOTICE attribution)
- INV-SLA-10: Cross-Platform Parity & SLA (Windows, Linux, macOS with 48h response / 5-day triage / 30-day remediation security SLA)
